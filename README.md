# EXE Dragon Egg Hoard · hosted files

Hosted files for the **EXE Dragon Egg Hoard** StreamElements widget by form&soul.exe (v1.0.0-rc.1).

- `engine/egghoard-engine.js` — widget engine
- `engine/egghoard-presenter.js` — presentation (egg, reveal, plaque, streak notices)
- `theme/` — 24 dragons + shiny variants, egg pieces, interface art, sound effects (`sfx/`), theme.json, presenter_config.json
- `fonts/` — Fraunces and Inter (SIL Open Font License 1.1, see OFL-*.txt)
- `index.html` — live preview

These files are loaded by the widget at runtime. Do not rename or move them.
